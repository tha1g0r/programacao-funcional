# Scala Estudos

Repositório de estudos em Scala, organizado por tópicos.

## Como rodar

No terminal, dentro da pasta do projeto:

```bash
sbt run
```

Ou, para rodar um arquivo específico:

```bash
sbt "runMain basico.olaMundo"
```

## Estrutura

- `src/main/scala/basico/` — conceitos básicos da linguagem
